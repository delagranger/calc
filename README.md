# Проект calc

Это мой первый проект на Python и первый многомодульный проект. Он был создан в рамках освоения базы языка Python.

## Технические особенности

### Обработка прошлого результата
Простой калькулятор я писал и раньше, в рамках освоения C#. Прошлая программа просто рассчитывала результат выбранной
операции и выводила его в консоль. Здесь же было решено добавить возможность работы с результатом предыдущей операции.

### История операций
Еще одна особенность этого проекта - просмотр истории операций. В специальном модуле history реализована механика
записи и чтения .json-файла. Сам .json хранится в домашней директории пользователя, а не в папке проекта.
Было интересно разрабатывать данный функционал, до этого момента с файловой системой я не работал. 

### Многомодульность
Раньше все мои програмки умещались в один файл. Работало, но в разработке было не совсем удобно.
На этапе проектирования calc познакомился с понятием многомодульности.
Как итог, программа разделена на несколько индивидуальных модулей:

  - модуль history, отвечающий за ведение истории операций
  - модуль maths, отвечающий за математические операции
  - и модуль ui, отвечающий за чтение и вывод данных в консоль
